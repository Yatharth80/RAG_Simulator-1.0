? What is RAG?

Retrieval-Augmented Generation (RAG) is a pattern where a language model answers using passages fetched from your documents, not only from what it memorized during training.

You index a knowledge base ahead of time (chunk → embed → store). At question time you embed the question, find the closest chunks, paste them into a prompt, and let the model write from that context. That is why RAG reduces hallucination on private or fresh facts: the model is steered by retrieved text.

Think of it as an open-book exam: the model can only “see” the pages you put on the desk for that question.

Common mix-up

  1. Guess relevant chapters
  2. Embed only those
  3. “Format” the query
  4. Call the model

Actual pipeline

  1. Chunk the whole corpus
  2. Embed & store every chunk (index)
  3. Embed the question
  4. Rank by similarity → top-k
  5. Build prompt (context + question)
  6. Generate from that prompt only
